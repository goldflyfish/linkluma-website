LinkLuma privacy

Clear about your data.

LinkLuma is published by Mykola Chornyi. The Windows app reads connection information on your device. An optional speed test connects to M-Lab, and this website is hosted by GitHub Pages.

What stays on your device

The app uses Windows network status and adapter traffic counters to show your connection and current download and upload activity. It saves settings, speed-test history, and recent speed-test start times locally. Saved test history can include adapter and network identifiers when they are available, so a result can be matched to the connection it measured.

The recent traffic graph keeps its readings in memory while the app runs, for up to ten minutes. It starts fresh when the app restarts.

Optional M-Lab speed tests

If you choose to run a speed test, LinkLuma asks for your agreement before the first test. The test sends and receives generated traffic with M-Lab. M-Lab receives your public IP address and test results, publishes test data, and retains it indefinitely. Read M-Lab’s privacy policy before testing.

Clearing LinkLuma’s local speed-test history does not remove data already published by M-Lab.

This website

We have not added analytics or cookies to this site. GitHub Pages hosts it and logs and stores visitor IP addresses for security. See GitHub Pages information and the GitHub Privacy Statement.
